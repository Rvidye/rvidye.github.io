State the problem and the useful result first. Give the reader enough context to
decide whether this is the problem they are trying to solve too.

## The starting point

Describe the assumptions, constraints, and smallest example that explains the
problem. Link the relevant documentation or sources.

## Working it out

Walk through the key decision. Keep examples small and explain what the reader
should notice in each one.

```cpp
// Replace this with a small example that supports the explanation.
const auto result = investigate(question);
```

## What changed

Show the result and how you checked it. Mention limitations that matter to the
reader, then link to further details or the related project.
