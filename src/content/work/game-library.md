GAME is a GPU computation library that abstracts CUDA, OpenCL, Metal compute, and DirectX compute behind a single interface, so kernels can be developed once and run across different hardware.

It won Project Expo 2K23 at MIT ADT University in April 2023, for innovation in GPU computation, where it demonstrated performance portability across heterogeneous hardware.
